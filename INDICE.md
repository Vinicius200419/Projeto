## 🚀 Executar Projeto

### Quick Start
```bash
cd c:\Projetos\Projeto_Android
build.bat full
```

### Ou manualmente
```
1. Android Studio → File → Open → Projeto_Android
2. Aguarde sincronização
3. Run → Run 'app'
```
