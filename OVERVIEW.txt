================================================================================
 FLUXO DE DADOS
================================================================================

LISTAR:
  MainActivity → ViewModel → RecipeDao → Room → LiveData → UI

ADICIONAR:
  AddEditActivity → ViewModel → RecipeDao → Room INSERT → MainActivity atualiza

EDITAR:
  MainActivity → AddEditActivity (carrega) → ViewModel → Room UPDATE → atualiza

DELETAR:
  MainActivity → Confirmação → ViewModel → Room DELETE → lista atualiza

================================================================================
 TROUBLESHOOTING RÁPIDO
================================================================================

ERRO: "Gradle sync failed"
SOLUÇÃO: File → Invalidate Caches → Restart

ERRO: "No device found"
SOLUÇÃO: 
  • Conecte telefone com USB
  • Ative "USB Debugging"
  • Ou crie emulador (Device Manager)

ERRO: "Cannot find SDK"
SOLUÇÃO: Crie local.properties com caminho do SDK

ERRO: "Build error"
SOLUÇÃO: ./gradlew clean build

ERRO: Port já em uso
SOLUÇÃO: Device Manager → AVD → Wipe Data
